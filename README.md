## The image

A front page, **"THE WORLD TODAY"**, drawn programmatically with Python
(stdlib only, hand-rolled PNG encoder) from real headlines of the day —
no AI image generator, so every word is sharp and legible:

- **Masthead + date:** Wednesday 18 November 2026 — 36 stories, 6 continents.
- **Lead stories:** Kerch Bridge span falls; US jets hit Qeshm; Nvidia $115.8bn.
- **Grid:** 33 numbered stories across six continents, colour-coded by region.
- **Map strip:** a thin schematic world map with numbered pins for the three leads.

## Run it

```
python3 main.py
```

writes `entry.png` (1024×1024, ≤1 MiB) to `/output`.
